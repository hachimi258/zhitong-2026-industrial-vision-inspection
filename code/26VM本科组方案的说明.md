# 核心方案文件 `26VM本科组方案.sol` 说明

> **归档说明**：`.sol` 是 VisionMaster 的方案文件，**本仓库不收录其本体**（169.8 MB，超过 GitHub 单文件 100 MB 上限）。
> 但它是本作品最核心的成果 —— 五类检测流程与全部训练模型都封装在其中。
> 因此本文**解析了该文件的真实内部结构**（它本身是一个 zip 容器，内含模块清单 XML），
> 用于在文件缺失的情况下保留可核对、可追溯的技术信息。
> **性质**：基于文件内部结构的实测解析，非竞赛文档原文。

## 五、为什么这个文件 169.8 MB

| 组成 | 大小 | 占比 |
|:---|:---|:---:|
| `MoudleFrame`（模型与流程主体） | 142.97 MB | 80.3% |
| `IMVSHPFeatureMatchModu`（木棍特征模板） | 23.31 MB | 13.1% |
| 方案级参数 `_70000+100+solution` | 3.47 MB | 1.9% |
| `VmServer.xml` + `GlobalScript_0` | 0.05 MB | <0.1% |
| 其余 48 个模块参数文件 | 0.003 MB | <0.1% |

**结论**：文件体量几乎全部来自**深度学习模型权重**与**特征模板**，
这也是它虽然只有 53 个条目却达 169.8 MB 的原因。
