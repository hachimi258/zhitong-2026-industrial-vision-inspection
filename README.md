## 各项目入口

### 🔍 智瞳工检 · AI 工业视觉智能检测系统

- **一句话成果**：把分类、计数、尺寸、缺陷、OCR 五类检测任务整合到一套 VisionMaster 系统中，
  607 张测试样本整体准确率 **98.52%**（分类 100% / OCR 99.17% / 缺陷 98.68% / 尺寸 97.56% / 计数 92.59%）
- **最值得读的三点**：① 用「杯口半径阈值」把叠杯这种形态问题转化为几何测量问题；
  ② OCR 采用「DL 字符定位 + DL 字符识别」两阶段而非端到端；③ 原文主动列出五项不足与改进路径
- **入口**：[zhitong-2026/README.md](zhitong-2026/README.md)
- **注意**：核心方案文件 `26VM本科组方案.sol`（169.8 MB）与演示视频（160.8 MB）超出 GitHub 单文件
  100 MB 上限，未入库；其**大小、SHA256、内部结构解析**完整记录在
  [zhitong-2026/results/03-提交材料清单.md](zhitong-2026/results/03-提交材料清单.md) 与
  [zhitong-2026/code/26VM本科组方案的说明.md](zhitong-2026/code/26VM本科组方案的说明.md)

### 🐕 中国软件杯 A7 · 基于机器狗的视觉目标检测

- **一句话成果**：A 榜 PP-YOLOE+ 三类检测 **F1 0.85396 / FPS 22.6** 双达标；
  B 榜在仅 100 张真实标注下用 Faster R-CNN 做教师模型生成伪标签，打通
  **PyTorch→ONNX→X2Paddle→Paddle 静态图**全链路，并以「去 NMS + 512 分辨率」把平台 FPS
  从 14.35 提到 **58.28（+306%）**
- **最值得读的三点**：① 本地验证 F1 0.9749 与平台 0.37529 相差 2.6 倍的根因（验证集分布 + 98.7% 伪标签）；
  ② 「竖棍形幻觉框」—— 赛制规则被模型 reward hack 的典型案例；
  ③ Step8 全部 15 轮的 `--iou 0.9` 因 OOM 分支漏传参数**从未生效**
- **入口**：[csu-2026-a7/README.md](csu-2026-a7/README.md)

## 归档约定（两个项目一致）

- **收录**：代码、说明文档、结果产出、演示材料、关键图片
- **不收录**：数据集本体、模型权重、第三方安装包、超过 GitHub 单文件上限的大文件
- **大文件**：凡是因体积或授权原因未入库的，一律在对应项目的
  `results/…提交材料清单.md` 中记录**大小 + SHA256 + 获取办法**
- **数据保真**：所有数字、路径、阈值、字节数均取自原始文档或实测，未做四舍五入或推算；
  文档未说明之处如实标注「未说明」，不做推测填补
