## 这是什么

这是 **2026 年（第 19 届）中国大学生计算机设计大赛 · 人工智能挑战赛（企业合作项目）** 参赛作品
**「智瞳工检 —— AI 工业视觉智能检测系统」** 的成果归档。

- **参赛编号**：2026035207
- **参赛学校**：上海中侨职业技术大学 · 信息工程学院
- **作品大类**：人工智能应用 / 挑战赛
- **开发平台**：海康机器人 VisionMaster 4.3.0（实际实现与调试使用 4.2.0）

作品基于 VisionMaster 平台与本地图像源，把**分类检测、目标计数、尺寸检测、缺陷检测、编号识别（OCR）** 五类任务
整合到同一套视觉系统中，实现自动判定、可视化标注与结果本地保存。

> **本仓库不收录数据集**（竞赛提供，约 6.8 GB），也不收录超过 GitHub 单文件 100 MB 上限的核心方案文件
> `26VM本科组方案.sol`（169.8 MB）与演示视频（160.8 MB）。这三项的**大小与 SHA256** 完整记录在
> [results/03-提交材料清单.md](results/03-提交材料清单.md)，并附重新获取/自行上传的办法。

### 五类任务的技术路线

| 任务 | 方法 | 关键点 |
|:---|:---|:---|
| 饮料分类 | 深度学习图像分类 | 旋转/亮度/对比度增强扩样；在准确率与推理速度间取舍模型规模 |
| 木棍计数 | 高精度模板匹配 | 调最小匹配分数、最大匹配个数、角度范围、尺度范围 |
| 纸杯尺寸 | Sauvola 二值化 + 形态学开运算 + 圆查找 | 以**杯口半径**区分单个/叠放，阈值 **1055 像素** |
| 纸杯缺陷 | 深度学习图像分割 | 杯壁污损/杯底污损/杯口损坏变形，按类别标签区域标注 |
| 编码识别 | 二值化 + 中值滤波 + 形态学 + **DL 字符定位 → DL 字符识别** 两阶段 | 带角度矩形框标注，适应倾斜/双排/点阵断裂 |

## 三个值得记录的点

### 1️⃣ 把"叠杯"这种形态问题转化为几何测量问题

纸杯叠放后杯口到相机距离变化，图像中杯口半径出现细微差异。作品用 **Sauvola 局部自适应二值化**分离杯口边缘 →
**形态学开运算**去孤立噪点 → **圆查找**（多卡尺方向搜索边缘点后拟合圆）输出半径 →
与阈值 **1055 像素**比较：超过判叠放（NG），未超过判单个（OK）。

> 这是全套方案里思路最干净的一环，耗时也最低（约 62.98 ms）。完整过程见 [results/02-技术方案与实现要点.md](results/02-技术方案与实现要点.md)。

### 2️⃣ OCR 用"定位 + 识别"两阶段，而不是端到端

编码位于罐底、点阵印刷、易断裂、常倾斜。作品先做二值化/中值滤波/形态学连接点阵，再用
**DL 字符定位**输出**带角度**的定位框（训练时按角度标注矩形框，可适应 360° 方向），
把定位框作为 ROI 交给 **DL 字符识别**。定位与识别分开，减少背景干扰。

输出示例：`0523BJ02;20260211`。

### 3️⃣ 最弱环节被明确承认并给出改进路径

木棍计数 92.59% 是唯一明显偏低的模块，根因是**目标粘连、遮挡、堆叠紧密**。
作品在总结里直接写明后续改用目标检测/实例分割提升鲁棒性，而不是回避。

其余改进方向（原文如实记录在 [results/02-技术方案与实现要点.md](results/02-技术方案与实现要点.md)）：
尺寸阈值自适应（当前阈值基于当前样本）、缺陷类别扩展、OCR 强反光适应性、以及接入实际相机/PLC 的工程化。
